# Record verification

1. **Ask first.** Get the URL, handle, CRD or document Blake holds before
   searching blind. What he knows outranks the index.
2. **Report findings, not verdicts.** Say what the record shows and where it
   doesn't match. Don't tell him what his history means.
3. **No negative from one method.** Before writing "not found", try a name
   search, the company or team page, LinkedIn and the registry PDF. Then write
   "didn't surface via X", not "does not exist".
4. **A partial record is not a refutation.** When a result seems to contradict
   Blake, look for the missing stage first.
5. **Known routes.** FINRA BrokerCheck PDFs fetch at
   `files.brokercheck.finra.org/individual/individual_{CRD}.pdf`. Co-hires show
   up as adjacent CRD numbers. A dated artifact dates the deal it documents,
   not the relationship behind it.
6. **Where it goes.** Findings go to a Sheets ledger, with columns for claim,
   source, date retrieved and status. Narrative goes in a Docs dossier.
   Personal records go only to private Drive, never to this repo.
7. Run `reviewer` before a dossier leaves Blake's hands.

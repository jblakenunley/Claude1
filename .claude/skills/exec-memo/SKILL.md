# Executive memo

1. Open with the four fields if they are missing: OBJECTIVE / ALREADY TRIED /
   OFF THE TABLE / DELIVERABLE.
2. Shape: one page. Recommendation, the few reasons that decide it, the
   guardrails, the decisions requested. No price tables, no account of how the
   analysis evolved, no long source lists, no side topics.
3. Platform or vendor choice: run the `snowflake` + `salesforce` panel (see
   `/CLAUDE.md`), add the no-new-platform option, and check both sides before
   recommending one.
4. Give the most space to the deciding point (often security or control), not
   to the implementation steps.
5. Output: a Docs artifact. Before it leaves Blake's hands, run `reviewer`.

# Ecosystem intelligence

1. **Data first, through Chablis.** Ask `chablis` for sources and provenance;
   reuse `chablis/feed` and the source registry before searching fresh. Every
   number carries a source and a retrieved-at timestamp.
2. **Freshness by class.** Static facts get a long horizon, ecosystem
   relationships a shorter one, and commercial or competitive signals a weekly
   or event-driven one. A fact past its horizon is marked STALE, not dropped.
3. **No rosy forecasts.** A forward projection gets a source or is labelled
   as Blake's or the vendor's view. Check any claim that flatters the tool
   before stating it.
4. **Output.** Numbers to watch go to a Dashboard artifact. A brief to read goes
   to a Docs artifact. A paid issue runs `reviewer` before it ships.
5. **Cost.** Recurring issues run as a scheduled task on the lowest tier that
   passes; synthesis across many sources runs on Opus.

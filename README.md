# chablis-scout (data branch)

Nightly output of the `chablis-scout` workflow: tool-quality signals for the
repos in `chablis/watchlist.json` on `main`. Public metadata about public
repositories only — no pulled data, ledger or recon findings ever land here.

- `scout/YYYY-MM-DD.json` — signals per repo, each with source URLs and retrieval time
- `logs/scout-YYYY-MM-DD.txt` — run log
